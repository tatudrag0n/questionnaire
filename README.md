# 熊谷高校のICT・生成AIアンケート（質問票 v8）

熊谷高校の生徒による探究活動用のアンケートです。学校の公式調査ではありません。中心テーマはICT導入による変化と今後の付き合い方で、授業でのICT利用と紙・ICTの比較、集中と自己管理、生成AIの利用経験、ICT導入で良くなった・悪くなったこと、紙とICTの使い分け希望、学校・社会への期待を尋ねます。設問16問・回答項目30項目（生成AIを使っていない場合は25項目）。回答はすべて任意で、質問を飛ばせます。

質問票の正本は`survey.js`です。AI利用状況による分岐、回答内容の検証もここで管理しています。設問や回答選択肢を変更する場合は、既存回答との混同を避けるため`VERSION`を更新し、公開画面・管理画面・運用文書の表記と検証を揃えてください。

管理画面（`/admin.html`）では、閲覧数・回答数の概要と日別推移、全設問の人数・割合、学年や任意の回答による絞り込み、クロス集計、CSV出力ができます。詳しくは[受付開始・管理集計](ADMIN-SETUP.md)を参照してください。

この調査で分かるのは、一時点における回答者の自己申告と主観的な比較です。客観的な学力測定、導入前後の測定、比較群はなく、ICTが学力や理解度を変えたという因果関係は検証できません。全国・国際調査は背景や比較の材料であり、熊谷高校生の回答の代わりにはなりません。

配布前に担当教員と設問・対象・説明文・データの保管方法を確認し、少人数で回答時間と質問の分かりやすさを試してください。
