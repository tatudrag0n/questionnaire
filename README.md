# 熊谷高校のICT・生成AIアンケート（質問票 v6）

熊谷高校の生徒による探究活動用のアンケートです。学校の公式調査ではありません。中心テーマは学習への影響で、授業や授業外のICT利用、授業中の学習外利用、紙中心の学びとICTを使う学びに対する本人の感じ方、学習目標や集中、生成AIの利用経験などを尋ねます。回答はすべて任意で、質問を飛ばせます。

質問票の正本は`survey.js`です。AI利用状況による分岐、回答内容の検証もここで管理しています。設問や回答選択肢を変更する場合は、既存回答との混同を避けるため`VERSION`を更新し、公開画面・管理画面・運用文書の表記と検証を揃えてください。

この調査で分かるのは、一時点における回答者の自己申告と主観的な比較です。客観的な学力測定、導入前後の測定、比較群はなく、ICTが学力や理解度を変えたという因果関係は検証できません。全国・国際調査は背景や比較の材料であり、熊谷高校生の回答の代わりにはなりません。

配布前に担当教員と設問・対象・説明文・データの保管方法を確認し、少人数で回答時間と質問の分かりやすさを試してください。
